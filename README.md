# JARVIS Ultimate Mobile

## Get your APK (phone only, ~5 minutes)

1. Create a free account at github.com and make a **new repository** (Public or Private).
2. Upload the files:
   - Tap **Add file → Upload files**, select everything INSIDE `jarvis_final`
     (do NOT upload the .zip itself — GitHub does not unzip it).
   - Hidden folders like `.github` are often skipped on phones. Check that
     `.github/workflows/main.yml` exists in your repo. If not:
     **Add file → Create new file**, type the name
     `.github/workflows/main.yml` and paste the file contents.
3. Open the **Actions** tab → **Build JARVIS APK** → wait for the green check (3–6 min).
   If it hasn't started, tap **Run workflow**.
4. Open the finished run → scroll to **Artifacts** → download **Jarvis**.
5. Unzip it → install **Jarvis.apk**
   (allow "Install unknown apps" for your browser/file manager when asked).
